# dagurleo's Homebrew tap

```sh
brew install --cask dagurleo/tap/markview
brew install --cask dagurleo/tap/t3agent37      # the app, with the t3agent37 command
brew install --formula dagurleo/tap/t3agent37   # the t3agent37 command alone (macOS, Linux)
```

| | |
|---|---|
| `markview` | [Markview](https://github.com/dagurleo/markview), a small native Markdown viewer for macOS, with Quick Look previews |
| `t3agent37` (cask) | [t3agent37](https://github.com/dagurleo/t3agent37), a menu-bar app that gives T3 Code cloud machines on Agent37 that sleep when idle. It links the `t3agent37` command |
| `t3agent37` (formula) | The `t3agent37` command alone, for macOS and Linux: `brew services start t3agent37` runs it in place of the app |
